# closet-visualizer（クローゼット管理アプリ）

## 概要

自分の持っている服を管理するためのコンソールアプリです。

買い物に行ったとき自分が持っている服とのバランスを考えて買うのが難しい。同じ服ばかり着てしまい、しまっている服を把握できていない。
そんな悩みを持っていたため、作りました。

## 機能

- 持っている服の情報登録（アイテム名・カテゴリー・色・シーン・季節・サイズ・価格・お気に入り度・メモ）
- 持っている服の情報更新（アイテム名・カテゴリー・色・シーン・季節・サイズ・価格・お気に入り度・メモ）
- 持ち物からごみ箱へのアイテム移動・ごみ箱から持ち物へのアイテム復元
- 持ち物アイテム・ごみ箱アイテムの一覧表示（アイテム名・カテゴリー・色・シーン・季節・お気に入り度）
- 持ち物アイテム・ごみ箱アイテムの情報表示（アイテム名・カテゴリー・色・シーン・季節・サイズ・価格・お気に入り度・メモ）
- 登録したアイテム情報の削除（物理削除）

## 使用技術

- Java 17（Eclipse Temurin）
- MySQL 8
- JDBC（MySQL Connector/J）
- Eclipse（開発環境）

## 工夫した点

### UI/UX面

- コンソール画面でも現在の操作画面がわかりやすいよう、画面ごとにメニューヘッダーを設置しました。
- TOPメニューに戻る操作は、メニューの変更があっても番号を崩さず操作できるよう、qキーの入力で実行できるようにしました。
- 登録負荷を軽くするため、必須項目はアイテム名とカテゴリーの2項目のみにしました。また、任意項目は入力なしでEnterキーを押下することでスキップできるようにしました。
- 編集時に関しても、入力なしでEnterキーを押下すると、更新作業を実施せず既存の登録値をそのまま維持する機能を実装しました。また、登録情報をクリアしたい場面にも対応できるよう、CLEAR（半角大文字）のみの入力で値をクリアする処理を実装しました。
- 持ち物一覧は、カテゴリーごとに並ぶようにし、どのカテゴリーの服をどれくらい持っているかが一目でわかるようにしました。また、第二ソートキーに作成日時を昇順で指定しました。過去に捨てた服の情報も確認できるよう、持ち物とごみ箱のアイテムを分けて閲覧できるようにしました。ごみ箱一覧は、更新日時項目を利用し、ごみ箱に入れた日時の昇順に並ぶようにしました。

### 実装面

- カテゴリー項目はマスタテーブル化し、並び替えを容易にしました。
- 色・シーン・季節の選択肢はEnumで管理し、そのID順に表示するようにし、シンプルな設計の中でもコードの保守性に気を配りました。

## セットアップ手順

### 前提条件
- Java 17（JDK）
- MySQL 8系

### 手順

1. このリポジトリをクローンする。

    `git clone https://github.com/kjk3-dev/closet-visualizer.git`

2. [MySQL Connector/J](https://dev.mysql.com/downloads/connector/j/) をダウンロードする（Select Operating Systemで「Platform Independent」→ZIP Archive版を選択）。
3. 解凍して出てきた `mysql-connector-j-x.x.x.jar` を、プロジェクト直下の `lib` フォルダに配置する。
4. MySQL Workbench などで `sql/schema.sql` → `sql/data.sql` の順に実行する。
5. `src/db.properties.sample` をコピーして `src/db.properties` にリネームする。
6. `db.properties` の `db.password` を、自分の環境のMySQLパスワードに書き換える。
7. `run.bat` をダブルクリックして起動する。
